# Portofolio Ali Fikri

Situs portofolio statis untuk Explore, GymBook, dan PT Tangguh Jaya Semesta.

Buka `dist/index.html` di browser untuk melihat situs secara lokal.

## Cloudflare Pages

Hubungkan repo ini lewat Git integration dengan branch produksi `main`, build command `exit 0`, dan build output directory `dist`. Ubah HTML, CSS, JavaScript, dan aset di `dist/` untuk memperbarui situs.
